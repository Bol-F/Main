# Python Beginner Course

This repository contains a beginner Python course with extra interview preparation. The goal is not only to learn syntax, but to become comfortable solving small problems, explaining your code, and showing projects to an employer.

Course files are inside the `Python_courses` folder.

## How to Study

1. Read one lesson file.
2. Run the examples with `python path/to/file.py`.
3. Solve the tasks in a separate practice file.
4. Review mistakes and write down what confused you.
5. Commit finished practice often so your GitHub history shows steady work.

## Missing Topics To Add Next

These topics are important for job interviews and real junior developer work:

## Daily Practice Routine

- 15 minutes: read or review one concept.
- 35 minutes: code tasks without copying.
- 15 minutes: debug and improve names, structure, and edge cases.
- 10 minutes: write notes about what you learned.
- 5 minutes: commit the finished work.

## Interview Checklist

You should be able to explain and use:

- `list`, `tuple`, `set`, and `dict`, including when to choose each one.
- Mutable vs immutable values.
- `==` vs `is`.
- Loops, conditions, functions, return values, and scope.
- Error handling with specific exceptions.
- File handling with `with open(...)`.
- OOP basics: class, object, method, inheritance, encapsulation, polymorphism, and abstraction.
- Basic Big O: why nested loops are usually slower than one loop.
- Common patterns: counting with dictionaries, removing duplicates with sets, two pointers, stacks, and sorting.
- Git basics: clone, branch, status, add, commit, push, pull request.
- SQL basics and simple API/JSON work.
- One or two finished projects that you can explain clearly.

## Portfolio Project Ladder

Start small and make each project clean enough to show:

1. Calculator CLI with input validation.
2. Number guessing game with retry logic.
3. To-do list CLI that saves tasks to a text or JSON file.
4. Contact book using dictionaries and JSON.
5. Expense tracker with CSV export.
6. Quiz app that loads questions from a file.
7. Weather CLI using an API and JSON parsing.
8. Library or student manager with SQLite.
9. Small Flask or FastAPI CRUD API.
10. Final project with tests, README, and clear Git history.

## Ready For Interviews

You are ready for beginner Python interviews when you can solve small tasks in 20-30 minutes, explain your choices out loud, handle edge cases, write functions instead of one long script, use Git comfortably, and discuss at least two projects from your GitHub.
